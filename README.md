# Приложение для анализа транзакций

## Описание:

Это приложение, в котором производится анализ траннзакций, представленных в прилагаемом в Excel-файле, 
Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять 
сервисы для выборки данных согласно запроса пользователя. 
В нем есть несколько функций, которые выполняют определенные задачи по обработке данных, имеющихся в Excel-файле,
а также возможность истребования сведений относительно курса валют и стоимости акций на вншених сервисах. 
Приложение оснащено декоратором log, который будет логировать инофрмацию по исполнению функций, 
а также их результаты или возникшие ошибки.:

1. функция, предоставляющая данные за указанный пользователм период времени, согласно имеющейся информации в 
Excel-файле:последние 4 цифры карты; общая сумма расходов; кешбэк (1 рубль на каждые 100 рублей).
2. функция, предоставляющая данные за указанный пользователм период времени, согласно имеющейся информации в 
Excel-файле, показывающая Топ-5 транзакций по сумме платежа.
3. функция, предоставляющая Курс валют.
4. функция, предоставляющая стоимость акций из S&P500.
5. функция возвращающая JSON-ответ со всеми транзакциями, содержащими запрос, обозначенный пользователем
    в описании или категории.
6. функция возвращающая траты по заданной пользователем категории за последние три месяца (от переданной даты).
